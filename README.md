# DeHub Docs

Documentation, blog and developer tools for [DeHub](https://dehub.io) and the $DHB token.

## Tech stack

- React + TypeScript, built with Vite
- Tailwind CSS and shadcn/ui

## Getting started

```sh
git clone https://github.com/maldoteth/dehubdocs.git
cd dehubdocs
npm install
npm run dev
```
